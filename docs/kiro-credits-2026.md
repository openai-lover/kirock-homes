# Kiroween 2026 development credits

공개 공식 자료 확인일: **2026-10-31 (Asia/Seoul)**. 아래는 2026 대회 안내이며 2025 혜택을 옮겨 적은 것이 아니다. 초기 공개 자료 조사와 이후 참가·신청 진행 상태를 구분한다. 계정 ID, 이메일, 신청 답변, 인증 정보, 지급 코드와 개인 사용량 수치는 이 배포용 문서에 기록하지 않는다.

## 현재 확인 상태

### 2026-11-04 재확인

- 공식 대회 FAQ/Rules/Resources를 다시 확인했다. 최종 제출 마감은 **2026-12-04 14:00 PST = 2026-12-05 07:00 KST**다. 참가 등록과 크레딧 신청만으로 프로젝트 제출이 완료되는 것은 아니다.
- 기존 공식 CLI의 인증이 유지됨을 확인했다. 새 `DetectiveProp.tsx` 구현과 타입 검사도 실제 Kiro CLI로 실행했으며 [원시 실행 기록](kiro/attraction-events.jsonl)과 [검사 결과](kiro/attraction-checks.json)를 보존했다.
- 로그인된 계정의 사용량 화면에서 무료 플랜과 개발 실행 후 사용량 증가를 확인했다. **그 화면에는 Kiroween 4,000크레딧 보너스 내역이 표시되지 않았다.** 이를 대회 크레딧 지급·등록 완료로 기록하지 않는다. 계정별 사용량 수치와 식별자는 배포 문서에 남기지 않는다.
- 연결된 Gmail에서 대회/크레딧 관련 최근 메일을 검색했으나 결과가 없었다. 이는 모든 이메일 계정의 승인 상태를 확인했다는 뜻이 아니다. 이전 신청을 중복 제출하거나 유료 업그레이드·오버리지를 켜지 않았다.
- 공식 요건은 Kiro의 실제 개발 활용과 그 설명이며, 일반 플레이어의 Kiro 계정 연결을 요구하지 않는다. 현재 게임에는 플레이어 Kiro 로그인이나 Kiro 크레딧 결제 기능이 없다. 게임의 선택적 사진 분석 API는 별도다.

아래 신청 진행 이력은 2026-10-31의 관찰과 사용자 보고를 보존한 것이다.

- **대회 참가 등록:** 같은 작업에서 브라우저의 참가 등록 완료 상태를 직접 확인했다. 참가 등록은 프로젝트 최종 제출과 별개다.
- **개발 크레딧 신청:** 사용자가 신청서를 제출했다고 보고했다. 이를 사용자 보고로 기록하며, Codex가 대신 제출했다고 주장하지 않는다.
- **직접 확인하지 않은 항목:** 신청 접수 완료 화면, 심사·인증 승인, 4,000 크레딧 지급, 지급 코드 수신·등록. 신청 완료 보고만으로 이 단계까지 완료됐다고 판단하지 않는다.

개인정보가 담긴 신청 화면이나 계정 식별자는 증빙으로 저장하지 않았다. 초기 웹 조회에서 폼을 읽지 못했다는 기록은 현재의 참가 등록·사용자 제출 보고를 부정하는 근거가 아니다.

## 확인한 지급 조건

Kiroween 2026 참가자는 **Kiro 크레딧 4,000개를 한 번 신청**할 수 있다. 팀의 각 적격 참가자도 대상이다. 신청 검토를 거치며 자동 지급이나 무조건 승인은 아니다. 정확한 Kiro user ID 또는 해당 Kiro 계정과 연결된 AWS account ID, 프로젝트 정보를 제출해야 한다. 잘못된 ID나 의심스러운 신청은 승인되지 않을 수 있다. 공식 검토·배부 안내는 **48 business hours**이며, 이를 달력 기준 48시간으로 보장해서는 안 된다. 추가 지급은 없다. ## 남은 확인과 등록 절차

1. 참가 등록은 완료 상태를 확인했고, [공식 크레딧 신청폼](https://forms.gle/ykuadfNyNdWdbJfH9)은 사용자가 제출했다고 보고했다. 이미 제출한 신청을 중복 제출할 필요는 없다.
2. 공식 검토 결과와 지급 안내를 확인한다. 아직 승인·지급을 확인한 기록은 없다.
3. 코드를 전달받으면 해당 Kiro 계정에 로그인한 상태에서 코드 URL을 열어 등록한다.
4. 사용량 대시보드에서 `kiroween` 접두사가 있는 지급 내역을 확인한다. Resources는 등록 후 약 1–2분 내 표시된다고 안내한다. [등록 절차](https://kiroween.devpost.com/resources)

Kiro user ID는 사용량 대시보드의 이메일·로그인 방식 옆에서 복사할 수 있다. AWS 계정 방식에서는 Kiro 프로필이 만들어진 계정의 12자리 ID를 확인한다. ID나 코드 자체를 이 저장소에 기록하지 않는다. [Kiro user ID 안내](https://kiro.dev/docs/billing/related-questions/), [AWS account ID 안내](https://kiro.dev/docs/enterprise/getting-started/)

초기 공개 자료 조사에서는 웹 조회 도구로 공식 신청폼 본문을 읽지 못해 모든 필수 입력란을 검증하지 못했다. 이후 상태는 위의 현재 확인 상태로 갱신했다. 사용자의 제출 보고를 신청 접수 화면의 직접 확인이나 승인 증거로 바꾸어 기록하지 않는다.

## 개발 실행 기록과 개인정보

실제 Kiro CLI 사용량을 별도로 조회한 이력은 있지만, 계정별 수치·요금제·초기화 정보는 이 배포용 문서에서 제거했다. 사용량은 계정 전체의 추정치이며 집계가 지연될 수 있으므로 특정 컴포넌트의 정확한 비용이나 크레딧 신청 승인 증거로 사용할 수 없다. 추가 결제·구독·오버리지 설정을 변경했다고 주장하지 않는다.

실제 작성 파일·명세·실행한 검증은 [Kiro 개발 증빙](kiro-usage.md)에 구분한다. 이전 한영 안내의 타입 검사나 브라우저 통과 기록을 이후 10개 언어 확장의 검사 결과로 재사용하지 않는다. 새 작업은 새 실행 기록으로 확인해야 한다.

## 개발 크레딧과 게임 AI는 별개

Kiro 크레딧은 프롬프트, 명세 수정, 개발 작업과 hook 실행 등에 사용하는 개발 도구 사용량이다. 일반 Kiro Free의 50 크레딧이나 첫 유료 업그레이드의 구독 보너스와 이번 대회 지급은 구분해야 한다. 대회 공개 지급 조건에는 유료 구독 업그레이드가 명시되어 있지 않다. [Kiro 가격·크레딧 설명](https://kiro.dev/pricing/), [대회 지급 조건](https://kiroween.devpost.com/resources)

이 게임의 선택적 사진 분석은 별도의 서버 환경변수 `AI_PROVIDER`, `AI_BASE_URL`, `AI_MODEL`, `AI_API_KEY`를 사용한다. Kiro 인증이나 개발 크레딧을 이 API 키 대신 연결하는 기능은 구현되어 있지 않다. Kiro 크레딧을 받았다는 이유로 게임의 외부 AI API 비용까지 충당된다고 판단하지 않는다. 샘플·사진 업로드·수동 선택·기본 대사는 외부 AI 키 없이 동작한다. [프로젝트 환경설정](../.env.example)
