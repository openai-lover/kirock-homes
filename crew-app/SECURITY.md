# Security scope

This is a local personal Crew app. Do not expose the backend or a personal Kiro session as a public AI service. Proxy signatures bind timestamp, method, exact target and request-body hash. Health is the only unsigned endpoint. Runtime turns use explicit capability denies; dialogue has no tools, vision can read its temporary image only.

The deterministic solver is the source of truth. Generated dialogue is optional, structurally validated and reviewed by a separate model call. Semantic review is fallible. Do not claim a mathematical guarantee for generated prose, or use the UI for sensitive photographs.

Disclose issues through a private GitHub security advisory where available. Never include account tokens, personal photographs, session homes or full runtime diagnostics in a public issue.
