# Historical UI tests
These tests describe the superseded notebook, hypothesis board, confrontation-button and four-panel comic interfaces. Preserved as historical regression specifications, not executed by the current Playwright config and not claimed as passing. Current chat flows replace them in tests/e2e, including staged evidence, free questions, mobile/RTL, focus, photo entry, accusations and server sharing. Existing photo normalization and vision fallback tests are retained and adapted in the current game.spec.ts. Engine/storage/route tests continue to run unmodified alongside new v2/chat coverage.
